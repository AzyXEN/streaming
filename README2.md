# Filmoteka

Стриминговый каталог фильмов на базе **OMDb API** с тёмно-фиолетовым интерфейсом, лентой трендов, поиском и фильтрацией по жанрам.

## Возможности
- Поиск фильмов по названию и быстрый выбор жанров
- Горизонтальная лента «Популярное сейчас» и сетка каталога
- Модальное окно с описанием сюжета, видеоплеером и системой отзывов/рейтинга
- Регистрация и вход пользователей с сохранением состояния в `localStorage`
- Избранное с сохранением между перезагрузками страницы

## Технологии
- HTML5, CSS3 (Flexbox, CSS Grid, медиазапросы)
- Vanilla JavaScript (ES-модули)
- OMDb API, `localStorage`
